# Survey 35 PWA v3

A touch-friendly scientific/RPN field calculator with an HP-35s-inspired key geometry and a survey tool dock. HP branding and artwork are intentionally not included.

## Install on iPhone with GitHub Pages
1. Upload the *contents* of this folder to a GitHub repository.
2. Repository Settings → Pages → Deploy from branch → main / root.
3. Open the HTTPS GitHub Pages URL in Safari.
4. Share → Add to Home Screen.

## v3 additions
- 6-column physical key geometry matching the supplied manual's keyboard organization.
- Left/right shifted key legends and behavior.
- RPN and ALG modes, DEG/RAD/GRAD, FIX/SCI/ENG/ALL.
- Trig, hyperbolic, logs, powers, percentages, probability, integer/rounding functions.
- Variables, STO/RCL, LASTx, stack roll/swap, flags and comparison menus.
- Base arithmetic and logic.
- Statistics accumulator, means, deviations, sums, and linear regression.
- Equations with numeric SOLVE and integration helpers.
- Program editor/executor for common RPN program steps.
- Physics constants catalog, unit/angle/time conversions, complex/vector tools.
- Survey inverse, traverse, curve, triangle, and chain tools.

This is a software reimplementation intended for field calculation. It is not an HP product and does not include HP logos or original artwork.
